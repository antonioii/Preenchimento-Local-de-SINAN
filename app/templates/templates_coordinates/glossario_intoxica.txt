Glossario de coordenadas - Intoxicacao Exogena

Objetivo
Este arquivo descreve, em linguagem simples, o que cada chave de coordenada representa no JSON intoxica.json.
A ideia e facilitar futuras revisoes do layout da ficha: caso o PDF mude, uma pessoa ou LLM pode correlacionar as novas posicoes com estes nomes.

Como ler
- Cada ponto tem page, x e y no JSON.
- page usa indice baseado em zero: page 0 = primeira pagina do PDF; page 1 = segunda pagina.
- Pontos terminados em numero geralmente sao casas individuais de campos digitados.
- Pontos com primeira_letra/letraINICIAL e ultima_letra/letraFINAL delimitam campos textuais longos.
- field_group mostra o grupo alinhado no JSON original, quando disponivel.

Exemplos
- data_da_notificacao1: e o primeiro digito referente a data no campo de dados gerais.
- data_da_notificacao2: e o segundo digito referente a data no campo de dados gerais.
- cnes_digito1 a cnes_digito7: sao os digitos do CNES do investigador no rodape; nao devem receber default automatico.
